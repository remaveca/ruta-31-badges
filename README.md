# Ruta 31 Badges

Repositorio central de **badges dinámicos e indicadores de estado** para todo el ecosistema de **Ruta 31**.

---

## 📌 Propósito y Arquitectura

Este repositorio aloja y expone métricas y estados de calidad, compilación y despliegue para los proyectos de **Ruta 31** mediante [Shields.io](https://shields.io/) y GitHub Pages:

- **Versión de Release:** Indicador de versión semántica (\semantic-release\).
- **Estado de Compilación / CI:** Resultados de pipelines en GitHub Actions.
- **Cobertura de Pruebas:** Métricas de tests unitarios e integración.
- **Salud del Sistema:** Estado de componentes y microservicios.

---

## 🗂️ Estructura de Endpoints de Badges

- \elease/\: Badges de releases y tags estables.
- \uild/\: Estados de build de GitHub Actions.
- \coverage/\: Métricas de cobertura de código.
- \docs/\: Estado de publicación de portales de documentación.

---

## 🔒 Seguridad
Este enfoque permite publicar badges en proyectos públicos y privados sin exponer credenciales ni código fuente sensible.
